가상 시각

    이번에는 어떻게 복구될까요?

    같은 "업링크 회선 다운"이어도 복구되는 이유는 여러 가지입니다. 고른 원인에 맞춰 원인 확인·조치·문자가 달라집니다. (원인 내용은 제가 만든 가상 사례입니다.)

    파란 띠 = 이벤트 시간(시작~종료, 점선), 밝은 띠 = 하이드레이션 타임(축구), 회색 띠 = 하프타임(축구). 모든 일정·수치는 가상입니다.

    월초·월말·매주에 자료를 보내는 고객사에 5분 단위 회선별 트래픽을 보내는 일. 정기 발송하는 고객사만 고를 수 있습니다. 고객사·회선은 모두 가상입니다.

    1. 요청 조건

    고객사 대상 월 기본은 지난달 1일부터 말일까지 한 달치 시작일 끝나는 날 회선

    이번 달 발송 현황

    정기적으로 자료를 보내는 고객사만 나옵니다. 눌러서 펼치세요.

    Admin
    사람이 켜 둔 상태입니다. Admin down이면 누가 일부러 끈 것입니다.
    
        
    Link
    실제 연결 상태입니다. Link down이면 선이 끊겼거나 상대가 꺼진 것입니다.
